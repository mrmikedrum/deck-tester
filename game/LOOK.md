# The game's look

Grimoire is the table's theme. Its colours, materials and painters live in `client/src/theme/grimoire/`.
The [design intent](tools/look/intent.md) defines the goals and limits.

## Record a round

From the repository root, fill the fixture art cache once with `bin/deckmaster game --fill-cache`.
From `game/`, run:

```sh
npm ci
npx playwright install chromium
npm run look -- <round-name>
```

The runner builds the TypeScript client and serves scripted fixtures on local, ephemeral ports.
It writes `.deckmaster/look/<round-name>/manifest.json` and refuses to overwrite an existing round.
The packet contains:

- Eight lossless 2420×1668 stills at 1210×834 CSS px and DPR 2. Turns 4, 9 and 15 come from the
  checked-in [design boards](../tests/fixtures/boards/design-pass.json), generated by
  [design-boards.js](tools/design-boards.js). The same still tools capture combat, the stack,
  a nameplate focus, a spread and the hand.
- The sampled [layout audit](tools/packet.js) of the drawn table on the five gated stills.
  Read the spread, nameplate and hand visually. A failing audit is evidence to carry into the round.
- Two short motion reels at 15 fps, a cast through resolution and an attack through combat.
  Each has numbered review sheets and telemetry. With FFmpeg installed the runner keeps MP4s and
  removes the intermediate frames. Otherwise the frame sequences serve as the clips.

For a targeted recheck, run `node tools/combat-stills.js <outdir> <moment> --audit` or
`node tools/chrome-stills.js <outdir> <moment>` against the built client. The recorder, `node tools/reel.js`, takes `--viewport 1210x834` for the
iPad's landscape size.

## Work the round

1. Record a baseline. Give independent [witnesses](tools/look/witness.md) the packet, the intent
   and a focus brief. Keep the branch, prior judgments and proposed fixes out of their briefs.
2. [Consolidate](tools/look/merge.md) witnessed findings and hand off cross-lane items. The
   **3D scene lane** owns `client/src/scene/three/`, the Grimoire faces in
   `client/src/theme/grimoire/`, and `client/src/layout/`. The **HTML chrome lane** owns
   `client/src/chrome/` and `client/src/app/`. Agree on ownership of shared changes before editing.
3. Each lane [fixes](tools/look/fix.md) on its own branch, records a fresh packet, and opens its own
   pull request. Run `npm run check` before opening the PR. All changes go through pull requests.
4. A [reviewer](tools/look/review-fix.md) checks the diff and the matching recordings.
5. Give the [blind judge](tools/look/judge.md) matching packets labelled X and Y, with the findings
   stripped of clues to version order. Keep the mapping with the coordinator. Any regression in
   look, taste or legibility blocks the round and goes to the owner, regardless of other gains.

The runner stops at capture. The coordinator supplies the briefs and runs the review.
