# Project state

Optional, short current handoff in `projects/<slug>/state.md`. Replace stale state; remove resolved items. Vision belongs in `vision.md`; decisions/preferences and current or explicitly abandoned ideas belong in consolidated `notes.md`.

- Active decks/branches: identifiers or mirror links and current purpose.
- Immediate question:
- Next step:
- Unresolved blocker/sync status, if any: last observation and needed receipt reference.

Exclude decklists, role counts, card-by-card analysis, research logs, completed-task history, reports and repeated vision. A routine turn need not change this file. [Workflow](../docs/manabox-workflow.md) owns publication.
