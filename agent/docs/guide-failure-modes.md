# Focused failure checks

Distilled from original guide sections 2, 3, 5, 8, 11–12. Use when relevant, not as a mandatory form.

| Risk | Check |
|---|---|
| Misremembered card | Enriched facts/all faces; explicit missing data; verify timing, cast/copy, ownership and duration. |
| Fun pile without infrastructure | Actual main/commander slots; role timing and dependency, not tag totals. |
| Theme drift | Compare package to accepted thesis/boundaries before import. |
| Win-more/setup burden | Early/mid/late usable turn; late mana is not early ramp, selection not necessarily advantage. |
| Role inflation | Unique slots versus overlapping, conditional coverage. |
| Pet-card ceiling as typical play | Preserve protected cards; predict floor/typical/ceiling separately from observed results. |
| Recycled rejected suggestions | Record reason and evidence/premise that would justify revisiting. |
| Wins/goldfish mistaken for fun | Thesis, participation, dead cards, ending and actual opponent feedback. |

Facts visibility prevents some errors; role assignment, interactions and social fit still need judgment.
